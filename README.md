## 💡 Sobre el Proyecto

Este repositorio contiene el código fuente de mi portafolio personal. Está diseñado como un sitio estático de altísimo rendimiento (**Astro SSG**), optimizado para tiempos de carga inmediatos, accesibilidad y una estética moderna orientada al desarrollo frontend y de agentes de IA.

## 🛠️ Stack Tecnológico

- **Framework**: [Astro](https://astro.build/) (Static Site Generation / Islands Architecture)
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS
- **Despliegue**: Vercel

## 🚀 Ejecución Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/lucaszhh/my-portfolio.git
cd my-portfolio

# 2. Instalar dependencias
npm install

# 3. Servidor de desarrollo
npm run dev
```

Abre `http://localhost:4321` en tu navegador.
